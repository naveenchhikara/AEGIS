**1. Create `src/actions/sampling/schemas.ts`:**

```typescript
import { z } from "zod";

const BucketEnum = z.enum([
  "NEWLY_SANCTIONED",
  "AMOUNT_WISE",
  "AGE_WISE",
  "DPD_WISE",
  "PRIOR_OBSERVATIONS",
]);

const BucketAllocationSchema = z.object({
  bucket: BucketEnum,
  pct: z.number().min(0).max(100),
  description: z.string(),
});

export const SaveCriteriaSchema = z.object({
  engagementId: z.string().uuid(),
  moduleCode: z.string().min(1),
  sampleSizePct: z.number().min(1).max(100),
  criteriaBuckets: z
    .array(BucketAllocationSchema)
    .length(5)
    .refine(
      (buckets) => {
        const sum = buckets.reduce((acc, b) => acc + b.pct, 0);
        return Math.abs(sum - 100) < 0.01;
      },
      { message: "Bucket allocations must sum to 100%" },
    ),
});

export const GenerateSampleSchema = z.object({
  engagementId: z.string().uuid(),
  moduleCode: z.string().min(1),
});

export type SaveCriteriaInput = z.infer<typeof SaveCriteriaSchema>;
export type GenerateSampleInput = z.infer<typeof GenerateSampleSchema>;
```

**`generateSampleAction(input: GenerateSampleInput)`**

- `getRequiredSession()` + check `hasPermission(roles, "audit_execution:manage_sections")`
- Validate input with `GenerateSampleSchema.safeParse(input)`
- Fetch sampling config via `getSamplingConfig(session, engagementId, moduleCode)` — if null, reject
- Fetch loan accounts via `getLoanAccountsForSampling(session, engagementId, moduleCode)`
- If no loan accounts, reject with "No loan accounts found for this module. Upload loan data first."
- Call `generateSample({ accounts, sampleSizePct: Number(config.sampleSizePct), criteriaBuckets: config.criteriaBuckets as BucketAllocation[] })`
- In a transaction:
  a. Reset any previously sampled accounts for this engagement+module: `updateMany({ where: { engagementId, moduleCode, tenantId, isSampled: true }, data: { isSampled: false, sampledAt: null, metadata: { ...existing, samplingBucket: null } } })`
  b. For each `sampledAccount` in result: `update({ where: { id: sampledAccount.accountId }, data: { isSampled: true, sampledAt: new Date(), metadata: { ...existing, samplingBucket: sampledAccount.bucket } } })`
  c. Update SamplingConfig: `update({ where: { id: config.id }, data: { isLocked: true, lockedAt: new Date(), lockedById: session.user.id, sampleGenerated: true, sampleGeneratedAt: new Date(), sampleCount: result.totalSelected } })`
- Return `{ success: true, data: { totalSelected: result.totalSelected, warnings: result.warnings } }` or `{ success: false, error: string }`
- `revalidatePath(\`/audit-execution/${engagementId}/rbia/sampling\`)`

**Important implementation notes:**

- The `metadata` field on LoanAccount is JSONB. When updating, spread existing metadata and add/update the `samplingBucket` key. Use Prisma's raw JSON update or fetch-then-update pattern.
- Decimal to number conversion: `Number(config.sampleSizePct)` and `Number(account.sanctionAmount)` etc. in the mapping layer before calling `generateSample`.
- The reset step (a) ensures re-generation replaces previous sample per CONTEXT.md decision.
