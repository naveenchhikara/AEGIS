Key integration insight: The bridge works by mapping ExaminationQuestion → ExaminationNode. Credit module leaf nodes in ExaminationNode correspond to questions in ExaminationQuestion (both use moduleCode). When instance-based scores are computed, they create/update ExaminationResponse records on the credit module's ExaminationNode leaves — the same records the existing scoring engine reads. This means the existing freeze flow consumes instance-based scores with zero changes to the scoring engine itself.

The mapping from ExaminationQuestion to ExaminationNode leaf: Each ExaminationQuestion has a moduleCode (e.g., "CRD-HLN"). The corresponding ExaminationNode leaves under that module's subtree are the scoring targets. The simplest mapping approach: for credit modules, create a single synthetic ExaminationResponse per credit module leaf node that aggregates all question compliance into one weighted score. The alternative (and better) approach per CONTEXT.md: each question's compliance % maps to a ScoreLabel, and these are set on corresponding leaf nodes under the credit module.

**Recommended approach:** Since ExaminationQuestion records do NOT have a 1:1 mapping to ExaminationNode leaf records (they are separate hierarchies), the bridge should:

1. For each credit module, compute the overall weighted compliance score from all question compliance results
2. Map that to a single ScoreLabel
3. Set that score on the credit module's ExaminationNode leaves (or on a single aggregation leaf per module)

Actually the cleanest approach: Since we want the existing scoring engine to just work, we create one ExaminationResponse per ExaminationNode leaf under the credit module. For credit modules that use instance-based scoring, the leaf nodes represent examination items that can be mapped 1:1 to questions. But if the tree structure doesn't match, we use the module-level score.

**Simplest correct approach:** Compute the module-level compliance score from all questions (weighted average of per-question compliance scores, each mapped through SCORE_VALUES), then set this as a single ExaminationResponse on the credit module node (depth 1) or distribute across its leaf nodes. Since the existing `computeModuleScore` traverses leaves, the most compatible approach is to set ScoreLabels on existing leaf nodes or create a synthetic leaf.

**Function 1: `getQuestionResponseTallies(session, engagementId, moduleCode)`**

Returns response tallies grouped by questionId for a credit module — input for `computeModuleComplianceScores`.

```typescript
export async function getQuestionResponseTallies(
  session: Session,
  engagementId: string,
  moduleCode: string,
): Promise<Map<string, ResponseTally[]>>;
```

Query approach:

1. Get all active questions for the module: `ExaminationQuestion WHERE tenantId AND moduleCode AND isActive = true`
2. Get all AccountExamResponse records for this engagement + those question IDs: `AccountExamResponse WHERE engagementId AND questionId IN [...] AND tenantId`
3. Group responses by questionId into a Map
4. Include questions with zero responses (empty arrays in the Map) — critical for "Not Examined" display

```typescript
const tenantId = extractTenantId(session);
const db = prismaForTenant(tenantId);

const questions = await db.examinationQuestion.findMany({
  where: { tenantId, moduleCode, isActive: true },
  select: { id: true },
});

const questionIds = questions.map((q) => q.id);

// Initialize Map with empty arrays for all questions
const tallyMap = new Map<string, ResponseTally[]>();
for (const qId of questionIds) {
  tallyMap.set(qId, []);
}

if (questionIds.length === 0) return tallyMap;

const responses = await db.accountExamResponse.findMany({
  where: { engagementId, questionId: { in: questionIds }, tenantId },
  select: { questionId: true, status: true },
});

for (const r of responses) {
  const existing = tallyMap.get(r.questionId) ?? [];
  existing.push({ status: r.status as "COMPLIANT" | "VIOLATION" });
  tallyMap.set(r.questionId, existing);
}

return tallyMap;
```

**Function 2: `computeAndApplyInstanceScores(session, engagementId, moduleCode)`**

The bridge function. Computes compliance scores for a credit module and upserts ExaminationResponse records on the credit module's leaf ExaminationNodes.

Strategy: Since ExaminationQuestion and ExaminationNode are separate hierarchies (questions are account-level checks, nodes are the RBIA examination tree), the bridge works at the module level:

1. Get response tallies via `getQuestionResponseTallies`
2. Compute per-question compliance results via `computeModuleComplianceScores`
3. Compute a weighted average ScoreLabel for the module from all question results
4. Find all leaf ExaminationNodes under this credit module (using path prefix match)
5. For each leaf node, upsert an ExaminationResponse with the computed ScoreLabel

The weighted average: For each question with a non-null scoreLabel, use SCORE_VALUES to get the numeric score, multiply by the question's weight, sum and divide by total weight. Then map back to ScoreLabel.

```typescript
export async function computeAndApplyInstanceScores(
  session: Session,
  engagementId: string,
  moduleCode: string,
): Promise<{ scoredLeafCount: number; moduleScore: number | null }>;
```

Implementation:

```typescript
const tenantId = extractTenantId(session);
const db = prismaForTenant(tenantId);

// Step 1: Get tallies and compute compliance
const tallies = await getQuestionResponseTallies(
  session,
  engagementId,
  moduleCode,
);
const complianceResults = computeModuleComplianceScores(tallies);

// Step 2: Get question weights for weighted average
const questions = await db.examinationQuestion.findMany({
  where: { tenantId, moduleCode, isActive: true },
  select: { id: true, weight: true },
});
const questionWeightMap = new Map(
  questions.map((q) => [q.id, Number(q.weight)]),
);

// Step 3: Compute weighted average score from question compliance
let weightedSum = 0;
let totalWeight = 0;
for (const result of complianceResults) {
  if (result.scoreLabel === null) continue; // skip Not Examined questions
  const score = SCORE_VALUES[result.scoreLabel];
  const weight = questionWeightMap.get(result.questionId) ?? 1;
  weightedSum += score * weight;
  totalWeight += weight;
}

if (totalWeight === 0) {
  return { scoredLeafCount: 0, moduleScore: null };
}

const moduleScore = weightedSum / totalWeight;

// Step 4: Map module score to a ScoreLabel for leaf nodes
// Use the compliance-to-score mapping on the percentage form
const { mapComplianceToScoreLabel } = await import("@/lib/instance-scoring");
const modulePercentage = Math.round(moduleScore * 100);
const moduleScoreLabel = mapComplianceToScoreLabel(modulePercentage);

// Step 5: Find credit module's ExaminationNode (depth 1)
const moduleNode = await db.examinationNode.findFirst({
  where: { tenantId, code: moduleCode, depth: 1, isActive: true },
  select: { id: true, path: true },
});

if (!moduleNode || !moduleScoreLabel) {
  return { scoredLeafCount: 0, moduleScore: null };
}

// Step 6: Find all active leaf nodes under this module
const leafNodes = await db.examinationNode.findMany({
  where: {
    tenantId,
    isLeaf: true,
    isActive: true,
    path: { startsWith: moduleNode.path + "." },
  },
  select: { id: true },
});

// Step 7: Upsert ExaminationResponse for each leaf node with the module ScoreLabel
// This makes the existing scoring engine "see" the instance-based scores
let scoredLeafCount = 0;
for (const leaf of leafNodes) {
  await db.examinationResponse.upsert({
    where: {
      engagementId_nodeId: { engagementId, nodeId: leaf.id },
    },
    create: {
      tenantId,
      engagementId,
      nodeId: leaf.id,
      score: SCORE_VALUES[moduleScoreLabel],
      scoreLabel: moduleScoreLabel,
      workingNotes: `Auto-scored from instance-based examination: ${modulePercentage}% compliance across ${complianceResults.length} questions`,
      flagForObservation: false,
      flagForActionPoint: false,
      respondedAt: new Date(),
    },
    update: {
      score: SCORE_VALUES[moduleScoreLabel],
      scoreLabel: moduleScoreLabel,
      workingNotes: `Auto-scored from instance-based examination: ${modulePercentage}% compliance across ${complianceResults.length} questions`,
      respondedAt: new Date(),
    },
  });
  scoredLeafCount++;
}

return { scoredLeafCount, moduleScore };
```
