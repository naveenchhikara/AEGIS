Create `src/components/rbia/compliance-summary.tsx` — a server-friendly component that displays per-question compliance percentages with ScoreLabel badges.

This component receives pre-computed data (not making its own queries) and renders a summary table of per-question compliance rates.

```typescript
import { Badge } from "@/components/ui/badge";
import { Card, CardContent, CardHeader, CardTitle } from "@/components/ui/card";
import { Progress } from "@/components/ui/progress";
import { cn } from "@/lib/utils";

```

**Props type:**

```typescript
export type ComplianceSummaryProps = {
  questions: Array<{
    questionId: string;
    questionText: string;
    totalAccounts: number;
    compliantCount: number;
    violationCount: number;
  }>;
  totalSampledAccounts: number;
};
```

**Component implementation:**

1. For each question, compute:
   - `compliancePercentage = totalExamined > 0 ? Math.round((compliantCount / totalExamined) * 100) : null` where `totalExamined = compliantCount + violationCount`
   - `scoreLabel = mapComplianceToScoreLabel(compliancePercentage)`

2. Render a Card with title "Compliance Summary" and a list of questions:

Each question row shows:

- Question text (truncated with ellipsis if long)
- Compliance percentage as a number (e.g., "78%") or "Not Examined" if null
- Color-coded badge showing the ScoreLabel abbreviation (FC/LC/PC/NC)
- A small progress bar showing the compliance % visually
- "X / Y examined" count (how many accounts were examined for this question)

Use the same SCORE_LABEL_COLORS pattern from the existing `score-drilldown.tsx`:

- FULLY_COMPLIANT: `bg-green-100 text-green-800`
- LARGELY_COMPLIANT: `bg-amber-100 text-amber-800`
- PARTIALLY_COMPLIANT: `bg-orange-100 text-orange-800`
- NON_COMPLIANT: `bg-red-100 text-red-800`

ScoreLabel abbreviations:

- FULLY_COMPLIANT: "FC"
- LARGELY_COMPLIANT: "LC"
- PARTIALLY_COMPLIANT: "PC"
- NON_COMPLIANT: "NC"

3. Show a summary row at the top:
   - Total questions examined (those with > 0 responses)
   - Overall compliance % (weighted average across all questions)
   - "Not Examined" count (questions with zero responses)

4. Empty state: if `questions` array is empty, show "No examination questions configured for this module"

**Styling notes:**

- Follow the existing Card-based layout pattern from `rbia-score-panel.tsx`
- Use `tabular-nums` for percentage displays
- Use `text-sm` for question text, `text-xs` for metadata
- Progress bars use the same height as module breakdown bars (`h-1.5`)
- Icons: import from `@/lib/icons` as required by project conventions
