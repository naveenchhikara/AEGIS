Create a "use client" component `RbiaModuleGrid` that receives props:
- `modules: EngagementModuleScoreRow[]` — from `getEngagementModuleScores()` DAL (Phase 19)
- `engagementId: string` — for building links
- `moduleSelections: EngagementModuleSelection[]` — from `getModuleSelections()` DAL (Phase 19)

For each module, render a Card (shadcn/ui Card) containing:

1. **Module name** — `row.moduleName` as card title
2. **Progress bar** — shadcn/ui `<Progress>` showing `scoredCount / totalLeafCount` percentage
3. **Progress text** — e.g., "12 / 24 items scored — 50%"
4. **Current score** — `row.weightedScore` displayed as percentage (multiply by 100, Math.round)
5. **Status badge** — shadcn/ui `<Badge>`:
   - `scoredCount === 0` → "Not started" (gray/muted)
   - `scoredCount < totalLeafCount` → "In progress" (blue/default)
   - `scoredCount >= totalLeafCount` → "Complete" (green/success)
6. **Link** — entire card wrapped in `<Link href={/rbia/module/${moduleCode}?engagementId=${engagementId}}>` from next/link

Layout: CSS grid — 3 columns on lg, 2 on md, 1 on sm (`grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4`).

Module cards should feel like a Kanban-style status board per CONTEXT.md specifics.

Auto-selected modules (where the module code appears in `moduleSelections` with `isAutoSelected: true`) should have a subtle indicator (e.g., small "Auto" badge or icon). Manually added modules show "Manual" badge.

Import icons from `@/lib/icons` (not directly from lucide-react).
Import types from `@/data-access/rbia-scoring` and `@/data-access/rbia-examination`.

Check `src/generated/prisma/enums.ts` or `prisma/schema.prisma` for exact `ScoreLabel` enum values before using them. Use the actual enum value names, not abbreviated display labels.
