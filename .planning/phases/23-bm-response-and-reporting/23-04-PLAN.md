Query all data needed for the 8-section RBIA PDF in a single efficient fetch (or parallel Promise.all):

```typescript
const db = prismaForTenant(tenantId);

const [engagement, branchScore, actionPoints, observations, meetings] =
  await Promise.all([
    // Engagement with full details
    db.auditEngagement.findFirst({
      where: { id: engagementId, tenantId },
      select: {
        id: true,
        status: true,
        auditType: true,
        startDate: true,
        endDate: true,
        branch: {
          select: {
            name: true,
            code: true,
            branchType: true,
            zone: { select: { name: true } },
          },
        },
        auditPlan: { select: { planName: true, planYear: true } },
        teamMembers: {
          select: {
            user: { select: { name: true } },
            role: true,
          },
        },
        tenant: {
          select: {
            name: true,
            logoUrl: true,
          },
        },
      },
    }),

    // Frozen RBIA score (BranchRbiaScore)
    db.branchRbiaScore.findUnique({
      where: { engagementId },
      select: {
        compositeScore: true,
        ratingBand: true,
        moduleScores: true,
        scoringTreeSnapshot: true,
        frozenAt: true,
        frozenBy: { select: { name: true } },
      },
    }),

    // All ActionPoints for this engagement
    db.actionPoint.findMany({
      where: { engagementId, tenantId },
      orderBy: { serialNo: "asc" },
      select: {
        serialNo: true,
        title: true,
        description: true,
        severity: true,
        moduleCode: true,
        status: true,
        bmResponseText: true,
        bmResponseDate: true,
      },
    }),

    // All Observations for this engagement
    db.observation.findMany({
      where: { engagementId, tenantId },
      orderBy: { createdAt: "asc" },
      select: {
        title: true,
        condition: true,
        criteria: true,
        cause: true,
        effect: true,
        recommendation: true,
        severity: true,
        status: true,
      },
    }),

    // Meeting records
    db.engagementMeeting.findMany({
      where: { engagementId },
      orderBy: { createdAt: "asc" },
      select: {
        meetingType: true,
        attendees: true,
        minutes: true,
        signedOff: true,
        signedOffById: true,
        signedOffBy: { select: { name: true } },
        createdAt: true,
      },
    }),
  ]);
```

Return null if engagement not found. Otherwise return typed object:
`{ engagement, branchScore (with Decimal→number conversion for compositeScore), actionPoints, observations, meetings }`

Validate tenantId on branchScore (defense-in-depth) if it has a tenantId field.

**PdfScoreGauge helper** (inline in same file):

- Uses `<Svg>` with two `<Circle>` elements: background ring (gray) + foreground arc (colored)
- Props: `percentage: number`, `color: string`
- Background circle: `stroke="#e2e8f0" strokeWidth="8" fill="none"`
- Foreground circle: `stroke={color}` with `strokeDasharray="{arcLength} {gapLength}"` and `transform="rotate(-90 50 50)"` per research code example
- Arc calculation: `circumference = 2 * Math.PI * radius`, `arcLength = circumference * (percentage / 100)`, `gapLength = circumference - arcLength`

**RbiaReportDocument component:**

Props: `data` from `getRbiaReportData()` return type.

8 sections rendered as sequential Pages:

**Section 1: Cover Page**

- Bank name (data.engagement.tenant.name) prominently at top
- Bank logo if `tenant.logoUrl` exists (use `<Image>` component)
- Branch name and code
- "RBIA Audit Report" title
- Engagement period: `startDate — endDate`
- Rating band badge: large colored rectangle with rating text
- AEGIS logo small in footer

**Section 2: Executive Summary**

- Brief overview: "The RBIA audit of {branchName} was conducted from {startDate} to {endDate}. The composite RBIA score is {percentage}% ({ratingBand})."

**Section 3: Engagement Details**

- Branch info: name, code, type, zone
- Audit team: team members list with roles

**Section 4: Score Summary**

- PdfScoreGauge component rendered (visual circular gauge)
- Table: module code | module name | score % | rating band | weight

**Section 5: Detailed Scores**

- Parse scoringTreeSnapshot (JSONB → ScoreTreeNode[])

- Use View + Text with paddingLeft for indentation (depth \* 10pt)

**Section 6: ActionPoints Summary**

- Table header: # | Title | Module | Severity | BM Response | Status

**Section 7: Observations**

- For each observation: title header, then 5C fields (Condition, Criteria, Cause, Effect, Recommendation)

**Section 8: Meeting Minutes**

- Opening meeting: attendees list, minutes text, signed off by
