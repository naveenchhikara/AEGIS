  session: Session,

```

Wait — per CONTEXT.md and research, the recommendation is to add `removalReason` to the schema. But the current DAL uses `delete()`. Two viable approaches:

- **Approach A (Audit trail only):** Keep delete(), pass reason to setAuditContext in the server action. Simpler but reason not queryable.
- **Approach B (Schema field):** Convert delete to update (set removalReason, then delete). But this is pointless — the record is deleted.
- **Approach C (True soft-delete):** Add `removedAt DateTime?` + `removalReason` fields. Update instead of delete. Filter active records with `removedAt: null`.

Use **Approach A** for simplicity — the Prisma schema `removalReason` field serves as documentation intent, and the actual reason is recorded via audit context in the server action. The `removeModuleSelection` DAL signature still accepts `reason` to pass through to the server action layer. But wait, the DAL itself doesn't set audit context — the server action does. So the DAL just needs the reason for the audit trail set by the server action.

**Simplest correct approach:** Keep the DAL delete, add `reason` to the DAL signature for API contract consistency, and have the server action set audit context with the reason before calling the DAL. The `removalReason` Prisma field exists for potential future soft-delete but is NOT used in this phase.

// 4. Scored-items guard — prevent removal of modules with existing examination responses
const db = prismaForTenant(session.user.tenantId);

// Find the module node to get its path for descendant lookup
const moduleNode = await db.examinationNode.findFirst({
  where: { id: validated.moduleNodeId, tenantId: session.user.tenantId },
  select: { id: true, path: true },
});

if (!moduleNode) {
  return {
    success: false,
    error: "Module not found.",
    code: "NOT_FOUND",
  };
}

// Find all leaf descendants of this module
const descendantLeaves = await db.examinationNode.findMany({
  where: {
    tenantId: session.user.tenantId,
    isLeaf: true,
    path: { startsWith: moduleNode.path + "." },
  },
  select: { id: true },
});

if (descendantLeaves.length > 0) {
  const leafIds = descendantLeaves.map((n) => n.id);
  const scoredCount = await db.examinationResponse.count({
    where: {
      engagementId: validated.engagementId,
      nodeId: { in: leafIds },
    },
  });

  if (scoredCount > 0) {
    return {
      success: false,
      error: `Cannot remove module: ${scoredCount} item(s) have been scored. Clear all scores before removing.`,
      code: "CONFLICT",
    };
  }
}
```
