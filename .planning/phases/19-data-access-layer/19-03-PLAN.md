Create `src/data-access/rbia-findings.ts` following the 5-step DAL pattern:

1. **Import block:**
   - `import "server-only";`
   - `import { prismaForTenant } from "./prisma";`
   - `import type { AuthSession as Session } from "@/lib/auth";`
   - Import relevant enum types from `@/generated/prisma` (Severity, ActionPointStatus, ObservationStatus, ScoreLabel)

2. **Export types:**

   `ActionPointData`:

   ```
   { id, serialNo, title, description, severity: Severity, moduleCode, status: ActionPointStatus,
     sourceResponse: { id, node: { code, path, name } } | null,
     bmResponseText: string | null, bmResponseDate: Date | null, bmResponseDeadline: Date | null,
     createdById, createdAt, isCarriedForward: false }
   ```

   `CarryForwardActionPointData`:

   ```
   Omit<ActionPointData, "isCarriedForward"> & { isCarriedForward: true, originalEngagementId: string }
   ```

   `ObservationData`:

   ```
   { id, title, condition, criteria, cause, effect, recommendation, severity: Severity,
     status: ObservationStatus, engagementId: string | null, branchId: string | null,
     observationType: string, createdAt }
   ```

   `EngagementFindings`:

   ```
   { actionPoints: ActionPointData[], carryForwardActionPoints: CarryForwardActionPointData[],
     observations: ObservationData[] }
   ```

3. **`getEngagementActionPoints(session, engagementId): Promise<ActionPointData[]>`**:
   - `db.actionPoint.findMany({ where: { tenantId, engagementId }, orderBy: { serialNo: "asc" } })`.
   - Include `sourceResponse: { select: { id: true, node: { select: { code: true, path: true, name: true } } } }`.
   - Map to `ActionPointData` with `isCarriedForward: false as const`.

4. **`getEngagementObservations(session, engagementId): Promise<ObservationData[]>`**:
   - `db.observation.findMany({ where: { tenantId, engagementId }, orderBy: { createdAt: "desc" } })`.
   - Select only the fields in `ObservationData` type.
   - NOTE: `sourceActionPointId` does not exist yet on Observation model. Add a TODO comment: `// TODO Phase 20: Add sourceActionPointId to Observation schema for promote-to-observation link`.

5. **`getCarryForwardActionPoints(session, currentEngagementId, branchId): Promise<CarryForwardActionPointData[]>`**:
   - Step 0: Guard against null branchId — `if (!branchId) return [];` (AuditEngagement.branchId is nullable String?).
   - Step 1: Find the immediately preceding COMPLETED engagement for the same branch:
     ```
     db.auditEngagement.findFirst({
       where: { tenantId, branchId, id: { not: currentEngagementId }, status: "COMPLETED" },
       orderBy: { completionDate: "desc" },
       select: { id: true }
     })
     ```
   - Step 2: If no preceding engagement, return empty array.
   - Step 3: Fetch open/unresolved APs from the preceding engagement:
     ```
     db.actionPoint.findMany({
       where: {
         tenantId,
         engagementId: precedingEngagement.id,
         status: { in: ["ISSUED", "BM_RESPONSE_DUE", "BM_RESPONDED"] },
         carriedForwardToEngagementId: null,
       },
       orderBy: { serialNo: "asc" },
       include: { sourceResponse: { select: { id: true, node: { select: { code: true, path: true, name: true } } } } }
     })
     ```
   - **Status mapping (document in code comment):** CONTEXT.md says "OPEN + PARTIALLY_RESOLVED" — mapped to actual enum values: OPEN = `ISSUED` + `BM_RESPONSE_DUE`, PARTIALLY_RESOLVED = `BM_RESPONDED`. Combined: `["ISSUED", "BM_RESPONSE_DUE", "BM_RESPONDED"]`.
   - `carriedForwardToEngagementId: null` ensures APs already forwarded to another engagement are excluded.
   - Map results to `CarryForwardActionPointData` with `isCarriedForward: true as const` and `originalEngagementId: precedingEngagement.id`.

6. **`getEngagementFindings(session, engagementId, branchId): Promise<EngagementFindings>`**:
   - Calls the three functions above in parallel using `Promise.all([getEngagementActionPoints(...), getCarryForwardActionPoints(...), getEngagementObservations(...)])`.
   - Returns `{ actionPoints, carryForwardActionPoints, observations }`.
