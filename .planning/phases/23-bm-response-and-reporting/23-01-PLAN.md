**DAL function** — Create `src/data-access/rbia-bm-response.ts`:

2. Import `prismaForTenant` from `@/data-access/prisma`
3. Import `AuthSession` from `@/lib/auth`

Export `getBmResponseBatchForEngagement(session: AuthSession, engagementId: string)`:

- Extract tenantId from session
- Query `bmResponseBatch.findFirst` where `{ engagementId, tenantId }` with `include`:
  - `engagement: { select: { id, branch: { select: { name } }, auditPlan: { select: { planName } } } }`
- If no batch found, return `null`
- Query `actionPoint.findMany` where `{ engagementId, tenantId, status: { in: ["ISSUED", "BM_RESPONSE_DUE", "BM_RESPONDED"] } }` ordered by `serialNo asc`, select: id, serialNo, title, description, severity, moduleCode, status, bmResponseText, bmResponseDate, sourceResponseId
- Return typed object: `{ batch, actionPoints }` with batch containing id, deadline, status, totalActionPoints, respondedActionPoints, and engagement branch name

**Server page** — Create `src/app/(dashboard)/auditee/[engagementId]/action-points/page.tsx`:

1. `getRequiredSession()` → session
2. Permission check: `hasPermission(userRoles, "action_point:bm_respond")` — redirect to `/dashboard` if denied
3. Extract `engagementId` from params (await params per Next.js 16 pattern)
4. Call `getBmResponseBatchForEngagement(session, engagementId)`
5. If no batch, show "No response batch found" empty state
6. Render `BmDeadlineBanner` with `deadline` and `status` props
7. Render progress counter: `{batch.respondedActionPoints} / {batch.totalActionPoints} addressed`
8. Render `BmResponseApCard` for each action point
9. Render submit button — disabled when `batch.respondedActionPoints < batch.totalActionPoints` — clicking opens `BmBatchSubmitModal`
10. Import icons from `@/lib/icons`
