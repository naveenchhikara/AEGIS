   ```typescript
   interface ValidationResult {

   }
   ```

   - Partial data handling: if optional fields have invalid values, apply defaults and add a warning
   - Collect module-specific metadata fields into the metadata object
   - Return ValidationResult with validRows, rejectedRows (with per-row per-field errors), and warnings

   - Remaining lines are data rows — split by comma, trim each, map to header keys
   - Handle quoted values (CSV fields with commas inside quotes)
   - Skip completely empty rows
   - Return headers array and rows as Record<string, string>[] (raw strings, no type conversion)

   - Use first worksheet (index 1 or name doesn't matter — banks export single-sheet files)

   - Remaining rows are data — map each cell to string using getCellValue
   - Skip completely empty rows (all cells empty)
   - Return same shape as CSV parser for uniform downstream processing
