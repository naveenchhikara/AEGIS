<objective>
Implement the 8-state engagement lifecycle state machine with prerequisite guards and role-based authorization, then create the server action that replaces the existing ad-hoc `update-engagement-status.ts`.

Purpose: The engagement state machine enforces RBIA audit practice — meetings before fieldwork, frozen scores before completion, team assignment before audit begins. This typed Record pattern ensures compile-time exhaustiveness: adding a new EngagementStatus enum value will cause a TypeScript error until the transition map is updated.

Output: `src/lib/engagement-state-machine.ts` (pure state machine), `src/lib/__tests__/engagement-state-machine.test.ts` (Vitest tests), and `src/actions/audit-execution/transition-engagement-status.ts` (server action replacement).
</objective>
