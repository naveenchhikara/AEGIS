**UI structure (per CONTEXT.md decisions — LOCKED):**

a) **Filter toggle:**

- Per CONTEXT.md: "filterable toggle to show/hide inactive"
- `useState<boolean>(true)` — default to showing only active
- Toggle: "Show inactive" checkbox or Switch component
- When enabled, inactive questions appear with visual treatment

b) **Table (shadcn/ui Table):**

Columns:

- **#** — displayOrder number
- **Question Text** — main text, truncated with tooltip for long text
  - Per CONTEXT.md: "Deactivated questions shown inline with strikethrough + 'Inactive' badge"
  - Inactive questions: `line-through text-muted-foreground` on the text + `<Badge variant="secondary">Inactive</Badge>`
- **Category** — category text or "—" if null
- **Weight** — numeric weight value
- **Critical** — `<Badge variant="destructive">Critical</Badge>` if isCritical, otherwise "—"
- **RBI Ref** — truncated reference or "—"
- **Responses** — count from `_count.accountExamResponses` (shows how many times this question has been answered)
- **Actions** — action buttons column

**Sorting:** Client-side sorting with useState. Click column header to sort ascending/descending. Use arrow icons to indicate sort direction.

c) **Action buttons per row:**

For active questions:

- **Edit** button (pencil icon) — opens EditQuestionDialog
- **Deactivate** button (archive icon) — calls `deactivateQuestion` server action with confirmation
  - If question has responses (`_count.accountExamResponses > 0`), show a confirmation dialog: "This question has been answered {N} times. Deactivating it will hide it from future examinations but preserve all historical responses."
  - If no responses, deactivate immediately with toast confirmation

For inactive questions:

- **Edit** button (pencil icon) — opens EditQuestionDialog
- **Reactivate** button (undo icon) — calls `reactivateQuestion` server action
  - Per CONTEXT.md: "Reactivation possible via button"
  - Toast: "Question reactivated"

Use `useTransition()` for action button pending states. Show `Loader2` spinner when pending.

d) **Empty state:**

- "No questions found for this module. Add the first question to get started."
