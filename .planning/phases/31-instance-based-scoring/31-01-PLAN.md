**Types to define:**

```typescript
export type ResponseTally = {
  status: "COMPLIANT" | "VIOLATION";
};

export type QuestionComplianceResult = {
  questionId: string;
  compliancePercentage: number | null; // null = no responses (Not Examined)
  scoreLabel: ScoreLabel | null; // null when compliance is null
  totalResponses: number;
  compliantCount: number;
  violationCount: number;
};
```

**Functions to implement:**

1. **`computeCompliancePercentage(responses: ResponseTally[]): number | null`**
   - Empty array returns `null` (Not Examined)
   - Count COMPLIANT / total responses \* 100
   - Return as integer percentage (Math.round)

2. **`mapComplianceToScoreLabel(compliancePercentage: number | null): ScoreLabel | null`**
   - `null` input -> `null` output
   - `100` -> `FULLY_COMPLIANT`
   - `>= 75 and < 100` -> `LARGELY_COMPLIANT`
   - `>= 50 and < 75` -> `PARTIALLY_COMPLIANT`
   - `< 50` -> `NON_COMPLIANT`
   - **IMPORTANT:** Threshold 75 is inclusive for LARGELY (75-99), threshold 50 is inclusive for PARTIALLY (50-74). This aligns with CONTEXT.md: "75-99% -> LC", "50-74% -> PC"

3. **`computeModuleComplianceScores(questionResponses: Map<string, ResponseTally[]>): QuestionComplianceResult[]`**
   - Takes a Map of questionId -> array of responses across all sampled accounts
   - For each question, computes compliance % and maps to ScoreLabel
   - Returns array of QuestionComplianceResult sorted by questionId
   - Questions with empty response arrays get null compliance and null scoreLabel
