**recordMeeting** action — atomically records a meeting AND transitions engagement status:

1. **Auth:** `getRequiredSession()` → userRoles, tenantId
2. **Permission:** `hasPermission(userRoles, "audit_execution:manage_team")` — reuse existing permission since meeting recording is part of engagement management (CAE, AUDIT_MANAGER, LEAD_AUDITOR all have this permission, matching the state machine's allowedRoles for OPENING_MEETING and EXIT_MEETING transitions)
3. **Validate:** `RecordMeetingSchema.safeParse(input)` → return `VALIDATION_ERROR` on failure
4. **Prisma:** `prismaForTenant(tenantId)`
5. **Transaction:**

Inside `db.$transaction(async (tx) => { ... })`:

a. `setAuditContext(tx, { actionType: "engagement_meeting.recorded", userId, tenantId, sessionId })`

b. Load engagement with prerequisites:

```typescript
const engagement = await tx.auditEngagement.findFirst({
  where: { id: validated.engagementId, tenantId },
  select: {
    id: true,
    status: true,
    branchId: true,
    teamMembers: { select: { id: true } },
    meetings: { select: { meetingType: true, signedOff: true } },
    branchRbiaScore: { select: { frozenAt: true } },
  },
});
if (!engagement) throw new Error("Engagement not found");
```

c. Determine target status based on meeting type:

```typescript
const targetStatus =
  validated.meetingType === "OPENING" ? "OPENING_MEETING" : "EXIT_MEETING";
```

d. Build EngagementContext and validate transition via state machine:

```typescript
const ctx: EngagementContext = {
  teamMemberCount: engagement.teamMembers.length,
  hasOpeningMeeting: engagement.meetings.some(
    (m) => m.meetingType === "OPENING" && m.signedOff,
  ),
  hasExitMeeting: engagement.meetings.some(
    (m) => m.meetingType === "EXIT" && m.signedOff,
  ),
  hasFrozenScore:
    engagement.branchRbiaScore?.frozenAt !== null &&
    engagement.branchRbiaScore !== null,
};
const transitionResult = canTransitionEngagement(
  engagement.status,
  targetStatus,
  userRoles,
  ctx,
);
if (!transitionResult.allowed) {
  throw new Error(transitionResult.reason);
}
```

e. Upsert meeting record:

```typescript
await tx.engagementMeeting.upsert({
  where: {
    engagementId_meetingType: {
      engagementId: validated.engagementId,
      meetingType: validated.meetingType,
    },
  },
  create: {
    tenantId,
    engagementId: validated.engagementId,
    meetingType: validated.meetingType,
    meetingDate: new Date(validated.meetingDate),
    attendees: validated.attendees as any,
    minutesText: validated.minutesText ?? null,
    keyDiscussionPoints: validated.keyDiscussionPoints ?? null,
    signedOff: false,
  },
  update: {
    meetingDate: new Date(validated.meetingDate),
    attendees: validated.attendees as any,
    minutesText: validated.minutesText ?? null,
    keyDiscussionPoints: validated.keyDiscussionPoints ?? null,
  },
});
```

f. Transition engagement status:

```typescript
await tx.auditEngagement.update({
  where: { id: validated.engagementId },
  data: { status: targetStatus },
});
```

After transaction:

```typescript
revalidatePath(`/audit-execution/${validated.engagementId}/rbia`);
revalidatePath(`/audit-execution`);
return { success: true as const, data: { status: targetStatus } };
```

Error handling: catch block returns `{ success: false, error, code: "TRANSITION_BLOCKED" }` if the error is from state machine rejection, otherwise `"INTERNAL_ERROR"`.

**signOffMeeting** action — sets signedOff=true on an existing meeting record:

1. **Auth:** `getRequiredSession()` → userRoles, tenantId
2. **Permission:** `hasPermission(userRoles, "audit_execution:manage_team")`
3. **Validate:** `SignOffMeetingSchema.safeParse(input)`
4. **Prisma:** `prismaForTenant(tenantId)`
5. **Transaction:**

Inside `db.$transaction(async (tx) => { ... })`:

a. `setAuditContext(tx, { actionType: "engagement_meeting.signed_off", userId, tenantId, sessionId })`

b. Load the meeting record:

```typescript
const meeting = await tx.engagementMeeting.findUnique({
  where: {
    engagementId_meetingType: {
      engagementId: validated.engagementId,
      meetingType: validated.meetingType,
    },
  },
});
if (!meeting) throw new Error("Meeting not found — record the meeting first");
if (meeting.tenantId !== tenantId) throw new Error("Meeting not found");
if (meeting.signedOff) return { id: meeting.id, alreadySignedOff: true };
```

c. Update meeting with sign-off:

```typescript
await tx.engagementMeeting.update({
  where: { id: meeting.id },
  data: {
    signedOff: true,
    signedOffById: session.user.id,
    signedOffAt: new Date(),
  },
});
```

After transaction:

```typescript
revalidatePath(`/audit-execution/${validated.engagementId}/rbia`);
return { success: true as const, data: { signedOff: true } };
```

Error handling: same pattern as recordMeeting.
