## Goal
Fix broken dashboard widgets, add loading/error infrastructure, and fix layout inconsistencies so all 4 demo roles (CEO, CAE, CCO, Auditor) see clean, functional dashboards and page transitions are smooth.

3 of 4 demo user dashboards (CAE, CCO, AUDIT_MANAGER) currently show permanent skeleton placeholders from unimplemented trend widgets. Page transitions show white flashes (no loading.tsx). Errors eject users from the dashboard shell. These issues would make the product look broken during a pilot demo.

## Output

- All 4 demo dashboards render without permanent skeletons or broken widgets
- Page transitions show a loading skeleton instead of white flash
- Errors stay within the dashboard layout
- ACE/ACB pages match the standard layout pattern
- Custom branded 404 page
