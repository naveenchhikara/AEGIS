<objective>
## Goal
Add "Next Step" CTAs and cross-navigation links across the audit lifecycle flow so users can navigate forward through RAM → Planning → Execution → Findings → Compliance without relying on the sidebar.

## Purpose

Resolves 5 remaining P1 navigation issues (ISS-006 through ISS-010). The audit lifecycle is a sequential flow, but pages currently have no forward links connecting them. Users hit dead ends after completing each step. This is the biggest remaining UX blocker for pilot demos.

## Output

- RAM detail page shows "Proceed to Audit Planning" CTA when assessment is APPROVED
- Audit Plans table rows link to `/audit-execution` showing created engagements
- Finding detail shows "View Compliance Status" link when observation is ISSUED or later
- Compliance table observation titles link to finding detail pages
- Compliance page shows "Prepare Board Report" CTA linking to governance
- Engagement detail and create pages have "Back to Audits" breadcrumbs
  </objective>

<acceptance_criteria>

## AC-1: RAM → Audit Planning forward navigation

```gherkin
Given a RAM assessment with status APPROVED
When the user views the assessment detail page
Then a "Proceed to Audit Planning" card with a button linking to /audit-plans is visible below the result card
```

## AC-2: Audit Plans → Engagements navigation

```gherkin
Given the Audit Plans page with existing plans in the table
When the user views the plans table
Then each row's engagement count is a clickable link to /audit-execution (filtered view)
```

## AC-3: Finding detail → Compliance link

```gherkin
Given a finding/observation with status ISSUED, RESPONSE, COMPLIANCE, or CLOSED
When the user views the finding detail page
Then a "View Compliance Status" link/badge is visible in the header area, linking to /compliance
```

## AC-4: Compliance → Finding detail navigation

```gherkin
Given the compliance table with items
When the user views the observation title column
Then the observation title is a clickable link to /findings/{observationId}
And a "Prepare Board Report" link to /governance is visible on the compliance page
```

## AC-5: Audit Execution back navigation

```gherkin
Given the engagement detail page or create engagement page
When the user is on either page
Then a "Back to Audits" breadcrumb link to /audit-execution is visible at the top
```
