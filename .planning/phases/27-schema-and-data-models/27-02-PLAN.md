Create `scripts/seed-exam-questions.ts` following the pattern established by `scripts/seed-rbia-housing.ts`.

**Structure:**

1. **Bootstrap** — Same pattern as seed-rbia-housing.ts:
   - Import PrismaClient from `../src/generated/prisma/client.js`
   - Import PrismaPg from `@prisma/adapter-pg`
   - Import pg from `pg`
   - Create pg.Pool + PrismaPg adapter + PrismaClient
   - Resolve tenantId from `--tenant-id=<uuid>` CLI flag or first tenant

2. **Question definitions** — TypeScript array of question objects with these fields:
   - `moduleCode`: String (always "CRD-HLN" for Housing Loans)
   - `text`: String (the question text)
   - `rbiReference`: String | null (RBI regulation area, NOT specific circular numbers — per CONTEXT.md decision)
   - `bestPracticeTip`: String | null (1-2 sentence practical guidance with common findings)
   - `category`: String (grouping: "Documentation", "Collateral & Valuation", "Sanction & Appraisal", "Disbursement", "Monitoring & Recovery", "PSL & Regulatory", "NPA & Provisioning")
   - `weight`: number (varied weights: most 1.0, critical items 1.5-2.0)
   - `isCritical`: boolean (true for PSL classification and NPA recognition questions)
   - `displayOrder`: number (sequential within category)

3. **Seed at least 20-25 questions** covering these RBI housing loan audit areas:

   **Documentation (4-5 questions):**
   - Loan application completeness (KYC, income proof, property docs)
   - Sanction letter issued with all terms and conditions
   - CERSAI registration within 30 days of mortgage creation
   - Title search and legal opinion obtained before sanction
   - Loan agreement executed with all required clauses

   **Collateral & Valuation (3-4 questions):**
   - Property valuation by approved panel valuer
   - Loan-to-value ratio within RBI prescribed limits (75-90% based on amount)
   - Insurance coverage (property + life) obtained and maintained
   - Periodic re-valuation of mortgage property

   **Sanction & Appraisal (3-4 questions):**
   - Borrower repayment capacity assessed (EMI/NMI ratio)
   - Credit bureau report (CIBIL/Equifax) obtained and evaluated
   - Sanctioning authority within delegated power limits
   - Pre-sanction visit/inspection conducted

   **Disbursement (2-3 questions):**
   - Stage-wise disbursement for under-construction property linked to progress
   - End-use verification within prescribed timeframe
   - No disbursement before mortgage creation

   **PSL & Regulatory (3-4 questions):** (these are CRITICAL)
   - PSL classification correct per RBI Priority Sector Lending guidelines
   - Housing loan amount within PSL qualifying limits
   - Borrower category (EWS/LIG/MIG) correctly classified
   - Interest rate within RBI benchmarking guidelines

   **NPA & Provisioning (3-4 questions):** (NPA recognition is CRITICAL)
   - NPA classification timely per RBI IRAC norms (90 days DPD)
   - Provision held as per applicable percentages
   - Restructuring/rescheduling properly documented and classified
   - Recovery efforts documented with timeline

   **Monitoring & Recovery (2-3 questions):**
   - Regular review of borrower account conducted
   - Early warning signals (EWS) monitored and escalated
   - SMA reporting accurate and timely

4. **Upsert logic** — For each question, use `prisma.examinationQuestion.upsert`:
   - `where`: `{ tenantId_moduleCode_text: { tenantId, moduleCode, text } }` (unique constraint)
   - `create`: all fields including tenantId
   - `update`: { rbiReference, bestPracticeTip, category, weight, isCritical, displayOrder, isActive: true }
   - This ensures idempotency: re-running updates metadata but doesn't duplicate

5. **Cleanup and logging** — Log count of upserted questions, close pg.Pool.

**RBI reference style (per CONTEXT.md):** Use general regulation area names:

- "Master Direction on Housing Finance" (not circular numbers)
- "Master Direction on PSL" for PSL questions
- "IRAC Norms" or "Master Circular on Income Recognition and Asset Classification" for NPA questions
- "Master Direction on KYC" for documentation questions
- "NHB Directions" where applicable
- null for questions that are general audit best practices without specific RBI backing

**Best practice tip style (per CONTEXT.md):** 1-2 sentences with practical guidance and common findings:

- "Check CERSAI registration within 30 days of mortgage creation — delayed registration is a common compliance gap"
- "Verify EMI/NMI ratio does not exceed 50% including all existing obligations"
- "Cross-check DPD calculation with system-generated report — manual overrides often mask true delinquency"
