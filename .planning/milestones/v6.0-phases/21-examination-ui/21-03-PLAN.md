Create a "use client" component `RbiaScorePanel` that receives props:
- `moduleScores: EngagementModuleScoreRow[]` — from `getEngagementModuleScores()` DAL
- `branchScore: BranchRbiaScoreData | null` — from `getEngagementBranchScore()` DAL (null if not yet frozen)
- `engagementStatus: string` — to control freeze button visibility

**Composite score section:**

1. Compute composite score: weighted average across all module scores (sum of `weightedScore * moduleWeight / totalWeight`). If `branchScore` exists and is frozen, use its `summary.compositeScore` instead.
2. Display as large percentage (e.g., "72%") with rating band badge next to it
3. Rating band colors and labels:
   - > 80%: "Very Good" — dark green (`bg-green-700 text-white`)
   - > 65%: "Good" — green (`bg-green-500 text-white`)
   - > 50%: "Satisfactory" — yellow (`bg-yellow-500 text-black`)
   - > 40%: "Moderate" — orange (`bg-orange-500 text-white`)
   - <=40%: "Poor" — red (`bg-red-600 text-white`)
4. Use shadcn/ui `<Badge>` for rating band label

**Total progress:**

- Sum `scoredCount` across all modules / sum `totalLeafCount` across all modules
- Display as text: "Total: 48 / 120 items scored — 40%"
- shadcn/ui `<Progress>` bar below the text

**Module breakdown:**

- For each module: horizontal bar showing module name, score percentage, and a mini progress bar
- Compact horizontal layout — 1 line per module, fits in a sidebar-like panel

**Freeze button:**

- shadcn/ui `<Button>` labeled "Freeze Score"
- **Disabled in Phase 21** — add `disabled` prop and a tooltip: "Available after all modules are complete"
- Only visible when `engagementStatus` is in a state where freezing makes sense (e.g., `REPORT_DRAFT` or later) — otherwise hide entirely
- Button will be wired to `freezeRbiaScore` server action in a future phase

**Layout:**

- Card-style container (`<Card>` from shadcn/ui)
- Placed above the module grid on the RBIA engagement dashboard
- Responsive: full width, content stacks vertically on mobile
