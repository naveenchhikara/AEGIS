**Deterministic shuffle function** (AEXM-01: randomized per account, stable on revisit):

```typescript
function shuffleQuestions<T extends { id: string }>(
  questions: T[],
  seed: string,
): T[] {
  // Simple hash-based deterministic shuffle
  const hash = (s: string) => {
    let h = 0;
    for (let i = 0; i < s.length; i++) {
      h = ((h << 5) - h + s.charCodeAt(i)) | 0;
    }
    return h;
  };

  // Seeded pseudo-random using account ID
  const seeded = [...questions].sort((a, b) => {
    const ha = hash(seed + a.id);
    const hb = hash(seed + b.id);
    return ha - hb;
  });

  return seeded;
}
```

Define this as a utility function at the top of the page file or in a shared utils file. The seed is the `selectedAccountId`, ensuring:

- Same account always shows same order (stable on revisit)
- Different accounts show different order (different seed)
