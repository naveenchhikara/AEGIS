  <action>
Create a "use client" component `RbiaExaminationTree` that receives props:
- `tree: ExaminationTreeNode[]` — from `getExaminationTree()` DAL (Phase 19), filtered to a single module's children
- `engagementId: string`
- `initialExpanded: string` — comma-separated node IDs from URL search param (passed from server page to avoid Suspense issues)
- `moduleName: string` — for sticky header display
- `moduleScore: { scoredCount: number; totalLeafCount: number; weightedScore: number | null }` — for sticky header

**TanStack Table setup:**

- Import `useReactTable`, `getCoreRowModel`, `getExpandedRowModel`, `flexRender`, `ExpandedState`, `ColumnDef` from `@tanstack/react-table`
- Set `getRowId: (row) => row.id` (use ExaminationNode UUID, NOT default array index — critical for URL state)
- Set `getSubRows: (row) => row.children` for recursive expansion
- Initialize `ExpandedState` from `initialExpanded` prop: parse comma-separated IDs into `Record<string, boolean>`. If `initialExpanded` is empty, call `buildDefaultExpanded(tree)` to expand depth 0 and 1 by default.
- On expand change, update URL via `router.replace` with `{ scroll: false }` — use `useRouter` + `usePathname` from `next/navigation`. Store expanded IDs as comma-separated `expanded` param. Do NOT use `router.push` (avoids history spam).

**Column definitions:**

1. **Name column** — indented by `row.depth * 20px` left padding. Shows expand/collapse chevron (ChevronRight / ChevronDown from `@/lib/icons`) for rows with children. Leaf rows show no chevron. Display `node.name`. If `node.isCritical`, show a small AlertTriangle icon from `@/lib/icons` next to name.
2. **Weight column** — show `node.weight` (small text, right-aligned)
3. **Score column** — for leaf rows (`node.isLeaf === true`): render 4 inline buttons "FC | LC | PC | NC" as a button group. Each button uses traffic-light color when selected: FC=green (`bg-green-500`), LC=yellow/amber (`bg-yellow-400`), PC=orange (`bg-orange-500`), NC=red (`bg-red-600`). Unselected buttons are `outline` variant. For non-leaf rows: show weighted roll-up percentage badge (e.g., "68%") computed by `computeRollUp(row.original)` — see RESEARCH.md Pattern 5.
4. **Status column** — for leaf rows: show current score label text or "—" if unscored. For non-leaf rows: show scored/total count (e.g., "8/12").

**Score button click handler:**

- Use `useOptimistic` (React 19) for immediate local state update
- On click: `startTransition(async () => { setOptimisticScore(...); await saveExaminationResponse({ engagementId, nodeId, scoreLabel, score }); })`
- Import `saveExaminationResponse` from `@/actions/rbia/examination` (Phase 20 server action)
- Show undo toast via `sonner`: `toast("Score updated", { action: { label: "Undo", onClick: () => revertScore() } })`
- When PARTIALLY_COMPLIANT or NON_COMPLIANT is selected, expand a sub-row below the leaf showing:
  - Textarea for working notes (min 500 chars guidance text)
  - Checkbox: "Flag for Action Point"
  - Checkbox: "Flag for Observation"
  - "Save notes" button that calls `saveExaminationResponse` with notes + flags
  - This inline expansion is a detail row, NOT TanStack Table expansion — use a separate state `expandedNotes: Set<string>` tracking nodeIds with notes panel open

**Critical item styling:**

- Leaf rows where `node.isCritical === true`: add `border-l-4 border-red-500` left accent
- If critical AND scored NON_COMPLIANT: add `bg-red-50 dark:bg-red-950` row background

**Filter toggle bar** (above the table):

- Three toggle buttons: "Unscored (N)" | "Flagged AP (N)" | "Flagged Obs (N)"
- Active filters stored in `useState<Set<ActiveFilter>>` where `ActiveFilter = "unscored" | "flaggedAP" | "flaggedObs"`
- Count badges computed from walking the full tree: count leaf nodes matching each filter
- When filters are active, pre-process the tree to compute a `Set<string>` of visible node IDs using the parent-chain visibility algorithm from RESEARCH.md Pattern 4
- Pass a `globalFilterFn` to TanStack Table that checks `visibleIds.has(row.id)`, OR pre-filter data before passing to `useReactTable` — choose whichever is simpler
- When filters active, auto-expand all parent chains of matching leaves so they are visible
- Clear visual indicator that filtered mode is active (e.g., highlighted filter bar background, "N items shown" text)

**Sticky header panel** (above filter bar):

- Fixed/sticky at top while scrolling
- Shows: module name, progress bar (`scoredCount / totalLeafCount`), current module score as percentage, rating band badge
- Use shadcn/ui `<Progress>` for progress bar, `<Badge>` for rating band
- Rating bands: >80% "Very Good" (dark green), >65% "Good" (green), >50% "Satisfactory" (yellow), >40% "Moderate" (orange), <=40% "Poor" (red) — per RBIA Policy 2020

**Roll-up computation** (client-side, from RESEARCH.md Pattern 5):
Implement `computeRollUp(node: ExaminationTreeNode): number | null` — recursive weighted average from children scores. Display as percentage badge on parent rows.

**General:**

- Import icons from `@/lib/icons` only
- Check `prisma/schema.prisma` for exact ScoreLabel enum values (FULLY_COMPLIANT vs FULLY etc.)
- Use Tailwind classes consistent with project conventions
- Table rendering: use `flexRender` pattern matching existing `findings-table.tsx` usage
