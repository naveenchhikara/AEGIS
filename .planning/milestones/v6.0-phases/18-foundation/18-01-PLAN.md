Create `src/lib/rbia-scoring-engine.ts` implementing these exports:

1. **`SCORE_VALUES`**: `Record<ScoreLabel, number>` mapping — FULLY_COMPLIANT=1.0, LARGELY_COMPLIANT=0.75, PARTIALLY_COMPLIANT=0.5, NON_COMPLIANT=0.0

2. **`CRITICAL_ITEM_CAP`**: Constant = 0.5

3. **`ScoredNode` type**: `{ nodeId: string; code: string; weight: number; isCritical: boolean; isLeaf: boolean; scoreLabel?: ScoreLabel | null; children: ScoredNode[] }`

4. **`NodeScoreResult` type**: `{ score: number | null; hasCriticalNonCompliant: boolean }`

5. **`RatingBand` type**: Union of "VERY_GOOD" | "GOOD" | "SATISFACTORY" | "MODERATE" | "POOR"

6. **`computeNodeScore(node: ScoredNode): NodeScoreResult`** — Recursive weighted roll-up:
   - Leaf: return SCORE_VALUES[scoreLabel] if scored, null if not
   - Parent: weighted average of scored children, excluding null (N/A) from denominator
   - Propagate hasCriticalNonCompliant upward from any child

7. **`computeModuleScore(moduleNode: ScoredNode): number | null`** — Calls computeNodeScore, applies critical-item cap at module level only (if hasCriticalNonCompliant && score > 0.5, cap at 0.5). Cap does NOT propagate to composite — composite uses already-capped module scores.

8. **`computeCompositeScore(moduleScores: Array<{ weight: number; score: number | null }>): number | null`** — Weighted average of module scores, excluding null modules from denominator.

9. **`getRatingBand(compositeScore: number): RatingBand`** — Thresholds per RBIA Policy 2020: >0.80 VERY_GOOD, >0.65 GOOD, >0.50 SATISFACTORY, >0.40 MODERATE, <=0.40 POOR

10. **`toPercentage(score: number): number`** — `Math.round(score * 100)`

Import `ScoreLabel` from `@/generated/prisma/enums`. No other dependencies.

Key implementation notes:

- `weightedSum / totalWeight` pattern (never pre-normalize weights)
- N/A handling: if `scoreLabel` is null/undefined, node is excluded from calculation
- Critical-item cap is applied in `computeModuleScore` (not inside `computeNodeScore`)
- Rating band thresholds use strict `>` (not `>=`) — 0.80 exactly is GOOD, not VERY_GOOD

Run all tests — they MUST all pass.
