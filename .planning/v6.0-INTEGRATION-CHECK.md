## Data Flow Consistency

**Pattern: Prisma → DAL → Server Action → UI Component**

All 11 RBIA pages follow the correct pattern:

1. **Server page calls DAL function** (uses session for tenantId isolation)
2. **DAL returns typed data** (Decimal conversion at boundary)
3. **Page passes data to client component**
4. **Component calls server action when needed**
5. **Server action validates, checks permission, executes in transaction**
6. **Component receives ActionResult<T> and displays feedback**

**Example Chain: Freeze**

```
rbia/page.tsx (server)
  → getEngagementModuleScores() + getEngagementBranchScore() [DAL]
  → RbiaScorePanel (client component)
    → freezeRbiaScore() (server action)
      → computeModuleScore(), computeCompositeScore() [Phase 18 engine]
      → BranchRbiaScore upsert + BmResponseBatch create [DB]
    → toast feedback + router.refresh()
```

**Result: ALL DATA FLOWS CORRECT ✓**
