Import `ActionPointData`, `CarryForwardActionPointData`, `ObservationData` from `@/data-access/rbia-findings`.

**Layout (per user decisions):**

1. **Empty state:** When no findings exist, show an illustration-style empty state with icon + "No findings yet" text + "+ Create Action Point" and "+ Create Observation" buttons (per locked decision: icon/illustration + CTA).

2. **Filter bar** at top:
   - Type toggle buttons: "All" | "Action Points (N)" | "Observations (N)" — per locked decision, filter-able by type
   - Status dropdown: "All statuses" / "DRAFT" / "ISSUED" / etc. — multi-select using existing Badge components
   - Carry-forward toggle: "Show carry-forward" checkbox (default on)
   - Each toggle shows count badge

3. **"+ New Finding" button** — opens inline expandable form (not a dialog/modal — per locked decision: inline expandable form).

4. **Unified list:** Map over filtered items, merging actionPoints and observations into a single array sorted by createdAt desc. Each row is a compact Card showing:
   - Serial number (APs) or "OBS" prefix (Observations)
   - Title (truncated to 1 line)
   - Type badge: "Action Point" (blue) or "Observation" (purple) — using shadcn Badge `variant="outline"` with custom colors
   - Severity badge: HIGH (red), MEDIUM (orange), LOW (yellow) — reuse existing severity color patterns
   - Status badge: DRAFT (gray), ISSUED (blue), BM_RESPONSE_DUE (amber), BM_RESPONDED (green), etc.
   - Module code (small muted text)
   - Carry-forward items: show a subtle "Carried forward" badge with link icon

5. **Row expand:** Clicking a row expands it inline to show:
   - Full description
   - Source examination response link (for APs): "Flagged from: [module > sub-module > item]" using `sourceResponse.node.path`
   - Edit button (only if status === "DRAFT" and canManageFindings) — opens FindingForm in edit mode
   - Delete button (only if DRAFT and canManageFindings)
   - "Promote to Observation" button (only for APs with canManageFindings)
   - BM response section (if bmResponseText exists): show response text and date

6. **State management:** Use `useState` for filter state (type, status, carryForward toggle), expanded row ID.

**Implementation:**
