**Create `src/components/rbia/add-module-dialog.tsx`:**

A "use client" component that renders a `Dialog` (non-destructive) with a scrollable checklist of ALL modules. Follow the `rbia-score-panel.tsx` pattern for async action handling.

```typescript
"use client";

import { useState, useTransition, useMemo } from "react";
import { useRouter } from "next/navigation";
import { toast } from "sonner";
import {
  Dialog,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from "@/components/ui/dialog";
import { Button } from "@/components/ui/button";
import { Checkbox } from "@/components/ui/checkbox";
import { Textarea } from "@/components/ui/textarea";
import { Label } from "@/components/ui/label";
import { ScrollArea } from "@/components/ui/scroll-area";
import { Plus, Loader2 } from "@/lib/icons";
import { addModuleSelectionAction } from "@/actions/rbia/examination";
```

Props interface:

```typescript
type AllModuleRow = { id: string; code: string; name: string };

interface AddModuleDialogProps {
  engagementId: string;
  allModules: AllModuleRow[];
  currentSelectionNodeIds: Set<string>; // Set of moduleNodeId already selected
  disabled?: boolean; // When status-gated or frozen
}
```

Internal state:

- `open: boolean` — dialog open state
- `checkState: Record<string, { checked: boolean; reason: string }>` — per-module checkbox + reason state
- Initialize `checkState` from `allModules` with `checked: currentSelectionNodeIds.has(m.id)` for each module
- `isPending` from `useTransition`

Derived values:

- `newlyCheckedModules` = allModules filtered to those checked in checkState but NOT in `currentSelectionNodeIds`
- `saveEnabled` = `newlyCheckedModules.length > 0` AND all newly-checked modules have non-empty reason (`.reason.trim().length > 0`)

Render:

1. `DialogTrigger` wraps a `Button` with `Plus` icon and text "Add Module" — `disabled` when prop is true
2. `DialogContent` with `DialogHeader` (title: "Add Examination Modules", description: "Select modules to add to this examination. A reason is required for each.")
3. `ScrollArea` (max-height ~400px) containing a list of all modules, each as:
   - `Checkbox` — checked state from `checkState[m.id].checked`, disabled if `currentSelectionNodeIds.has(m.id)` (already selected)
   - Module name label next to checkbox
   - If `currentSelectionNodeIds.has(m.id)`: show "(already selected)" muted text, checkbox disabled + checked
   - If newly checked (not in currentSelectionNodeIds but checked): show `Textarea` for reason (1-2 rows, placeholder "Reason for adding this module...")
4. `DialogFooter` with Cancel button and Save button. Save disabled when `!saveEnabled || isPending`. Save shows `Loader2` spinner when pending.

`handleSave`:

- `startTransition(async () => { ... })`
- Use `Promise.all` to call `addModuleSelectionAction` for each newly-checked module with `{ engagementId, moduleNodeId: m.id, reason: checkState[m.id].reason.trim() }`
- Count successes and failures
- If all succeed: `toast.success(...)`, close dialog, `router.refresh()`
- If some fail: `toast.error(...)` with failure count, still call `router.refresh()` to show partial success

On dialog close (`onOpenChange(false)`): reset `checkState` to initial state (re-derive from current props).

On dialog close: reset `reason` to empty string.
