**1. Add `generateBmEvidenceS3Key` to `src/lib/s3.ts`:**

Add a new exported function after the existing `generateS3Key` function:

```typescript
export function generateBmEvidenceS3Key(
  tenantId: string,
  actionPointId: string,
  extension: string,
): string {
  const uuid = crypto.randomUUID();
  return `${tenantId}/bm-evidence/${actionPointId}/${uuid}.${extension}`;
}
```

This uses a `bm-evidence` path segment (distinct from `evidence` used by observation/examination uploads) to keep S3 namespace clean.

- Return `{ success: true, data: { uploadUrl, s3Key, contentType: mimeType } }`
- Catch S3 errors (e.g., CredentialsProviderError when S3 not configured) and return user-friendly: `"Evidence upload is not configured. Please contact your administrator."`

**`confirmBmEvidenceUpload` action:**

- `getRequiredSession()` + `hasPermission(userRoles, "action_point:bm_respond")` guard

- Verify ActionPoint exists and belongs to tenant: `db.actionPoint.findFirst({ where: { id: actionPointId, tenantId, engagementId }, select: { id: true } })`
