Create `src/data-access/rbia-examination.ts` following the 5-step DAL pattern from `observations.ts`:

1. **Import block:**
   - `import "server-only";`
   - `import { prismaForTenant } from "./prisma";`
   - `import type { AuthSession as Session } from "@/lib/auth";`
   - `import type { ScoreLabel } from "@/generated/prisma";` (check actual import path — may be `@/generated/prisma/enums` or `@/generated/prisma`)

2. **Export types:**
   - `ExaminationResponseData`: `{ id, score: number | null, scoreLabel: ScoreLabel | null, workingNotes: string | null, flagForObservation: boolean, flagForActionPoint: boolean, respondedAt: Date | null }`
   - `ExaminationTreeNode`: `{ id, code, name, path, depth, isLeaf, parentId: string | null, weight: number, isCritical, riskCategory: string | null, regulatoryRef: string | null, applicableBranchTypes: string[], description: string | null, displayOrder, response: ExaminationResponseData | null, children: ExaminationTreeNode[] }`
   - Internal `FlatNode` type (not exported): Omit<ExaminationTreeNode, "children" | "response"> & { responses: ExaminationResponseData[] }

3. **`buildTree(flatNodes: FlatNode[]): ExaminationTreeNode[]`** — EXPORTED pure function:
   - First pass: create `Map<string, ExaminationTreeNode>` from flat array, set `response = node.responses[0] ?? null`, initialize `children = []`
   - Second pass: link children to parents via `parentId`. Nodes with no parentId are roots. If a parentId is not found in the map (orphaned — parent inactive), skip silently.
   - Sort children by `displayOrder` within each parent (recursive sort).
   - Sort roots by `displayOrder`.
   - Return roots array.

4. **`getExaminationTree(session, engagementId): Promise<ExaminationTreeNode[]>`**:
   - Extract `tenantId` from session.
   - Single `db.examinationNode.findMany({ where: { tenantId, isActive: true }, orderBy: [{ depth: "asc" }, { displayOrder: "asc" }] })` with `select` including all fields plus `responses: { where: { engagementId }, select: { id, score, scoreLabel, workingNotes, flagForObservation, flagForActionPoint, respondedAt } }`.
   - Convert `Decimal` fields at DAL boundary: `weight: Number(n.weight)`, `score: r.score !== null ? Number(r.score) : null`.
   - Call `buildTree(flatNodes)` and return.

5. **`getApplicableModules(session, branchCategory: string | null)`**:
   - Fetch all depth=1 active ExaminationNodes for tenant.
   - Filter in TypeScript: `m.applicableBranchTypes.length === 0 || (branchCategory && m.applicableBranchTypes.includes(branchCategory))`.
   - Return array of `{ id, code, name, applicableBranchTypes }`.

6. **`autoSelectModules(session, engagementId, branchCategory: string | null)`**:
   - Call `getApplicableModules()` internally.
   - `db.engagementModuleSelection.createMany({ data: applicableModules.map(...), skipDuplicates: true })`.
   - Each row: `{ tenantId, engagementId, moduleNodeId: m.id, isAutoSelected: true, selectionReason: branchCategory ? "Auto-selected for branch type: ${branchCategory}" : "Applies to all branch types" }`.

7. **`getModuleSelections(session, engagementId)`**:
   - `db.engagementModuleSelection.findMany({ where: { tenantId, engagementId }, include: { moduleNode: { select: { id, code, name } } }, orderBy: { createdAt: "asc" } })`.

8. **`addModuleSelection(session, engagementId, moduleNodeId, reason: string)`**:
   - `db.engagementModuleSelection.create({ data: { tenantId, engagementId, moduleNodeId, isAutoSelected: false, selectionReason: reason } })`.

9. **`removeModuleSelection(session, engagementId, moduleNodeId)`**:
   - `db.engagementModuleSelection.delete({ where: { engagementId_moduleNodeId: { engagementId, moduleNodeId } } })`.

IMPORTANT: Every DAL function must accept `session: Session` as first arg and extract `tenantId` from `session.user.tenantId`. Every query must include `WHERE tenantId`.
